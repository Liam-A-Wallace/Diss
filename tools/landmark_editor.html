Facial landmark editor

Select a feature or the full mesh, then drag its individual points to fit the face.

Overlaps resolve automatically. The last feature you edit takes priority in shared areas.
Wheel: zoom at cursor. Space + drag or middle mouse: pan. Click a point to select it. Arrow keys: move 1 pixel; Shift: 10 pixels.
For a feature contour, Add point inserts a handle halfway between the selected point and the next point. Drag it into place. You can also double-click an edge to add a point, or press Delete to remove one. Contours support 3 to 128 points.
